# 阿里 Java MySQL 强制规约

离线规则集：整理自《阿里巴巴 Java 开发手册》`1.3.0` 版的 `【强制】` 条款，并做了规约化转述。使用本 skill 不需要访问任何外部文件。

## 建表

- 表达是与否概念的字段，必须使用 `is_xxx` 命名，类型使用 `unsigned tinyint`。
- 表名、字段名必须使用小写字母或数字；不得数字开头；不得出现两个下划线中间只有数字。
- 表名不使用复数名词。
- 禁止使用 MySQL 保留字作为表名或字段名。
- 主键索引命名为 `pk_字段名`；唯一索引命名为 `uk_字段名`；普通索引命名为 `idx_字段名`。
- 小数类型使用 `decimal`，禁止使用 `float` 和 `double`。
- 如果字符串长度几乎相等，使用 `char` 定长类型。
- `varchar` 长度不要超过 5000；更长文本使用 `text`，并单独建表，用主键关联。
- 表必须包含三字段：`id`、`gmt_create`、`gmt_modified`。

## 索引

- 业务上具有唯一特性的字段，即使是组合字段，也必须建立唯一索引。
- 超过三个表禁止 join；需要 join 的字段数据类型必须完全一致，关联字段必须有索引。
- 在 `varchar` 字段上建索引时，必须指定索引长度，不要盲目使用全字段索引。
- 页面搜索严禁左模糊或全模糊查询；确有需要应走搜索引擎。

## SQL

- 不要用 `count(列名)` 或 `count(常量)` 替代 `count(*)`。
- `count(distinct col)` 只统计该列非 NULL 的不重复行；多列 distinct 要注意全 NULL 场景。
- 当某列全是 NULL 时，`count(col)` 返回 0，但 `sum(col)` 返回 NULL，必须处理 NULL 语义。
- 判断 NULL 必须使用 `IS NULL` 或 `IS NOT NULL`，不要使用等号比较。
- 分页查询中，如果 `count` 为 0，必须直接返回，避免继续执行分页语句。
- 不得使用外键和级联，外键概念必须在应用层解决。
- 禁止使用存储过程。
- 数据订正、删除、修改记录前，必须先 select 确认，避免误删误改。

## ORM 映射

- 表查询不得使用 `*` 作为字段列表，需要哪些字段必须明确写明。
- POJO 布尔属性不能加 `is`，但数据库字段必须加 `is_`，需要在 `resultMap` 中映射。
- 不要用 `resultClass` 作为返回参数；即使属性和字段一一对应，也需要显式 `resultMap`。
- SQL XML 参数使用 `#{}`，不得使用 `${}` 拼接用户输入，避免 SQL 注入。
- 不要使用 iBATIS 自带物理分页假象接口执行逻辑分页，应在 SQL 层分页。
- 不允许直接使用 `HashMap` 或 `Hashtable` 作为查询结果输出。
- 更新数据表记录时，必须同时更新 `gmt_modified` 为当前时间。
