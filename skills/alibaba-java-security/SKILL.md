# 阿里 Java 安全规约

## 使用方式

用于用户可达入口和安全敏感逻辑。读取 `references/mandatory-rules.md`，优先检查权限、输入验证、脱敏、注入、XSS、CSRF 和防重放。

## 检查流程

1. 标出所有用户可调用的接口、页面、表单、AJAX、外部参数和用户生成内容。
2. 对用户个人资源或功能，必须确认权限控制。
3. 对请求参数，必须确认有效性校验和边界约束。
4. 对敏感数据，必须确认响应和页面展示已脱敏。
5. 对 SQL 参数，必须确认参数绑定或元数据限定。
6. 对 HTML 输出，必须确认安全过滤或正确转义。
7. 对短信、邮件、电话、下单、支付等资源调用，必须确认防重放限制。

## 输出要求

安全相关修改必须明确说明保护了哪些入口、参数和数据。如果存在项目级统一拦截器或框架约束，要引用具体文件或机制。

## 详细规则

见 `references/mandatory-rules.md`。
