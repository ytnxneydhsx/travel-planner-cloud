# 阿里 Java 安全强制规约

离线规则集：整理自《阿里巴巴 Java 开发手册》`1.3.0` 版的 `【强制】` 条款，并做了规约化转述。使用本 skill 不需要访问任何外部文件。

## 强制规则

- 属于用户个人的页面或功能必须进行权限控制校验。
- 用户敏感数据禁止直接展示，展示前必须脱敏。
- 用户输入的 SQL 参数必须使用参数绑定或元数据字段值限定，防止 SQL 注入。
- 用户请求传入的任何参数必须做有效性验证。
- 禁止向 HTML 页面输出未经安全过滤或未正确转义的用户数据。
- 表单和 AJAX 提交必须执行 CSRF 安全过滤。
- 使用短信、邮件、电话、下单、支付等平台资源时，必须实现正确的防重放限制。

## 使用时的最低检查

- Controller、开放 API、页面渲染、表单提交和后台任务入口都属于用户输入边界。
- 只要返回个人信息、手机号、邮箱、身份证、账号、token、地址等敏感数据，就必须检查脱敏。
- 只要有动态 SQL、排序字段、筛选字段、分页参数、ID 列表，就必须检查参数绑定和白名单。
