# 阿里 Java 单元测试

## 使用方式

用于测试设计和验证。读取 `references/mandatory-rules.md`，确保测试自动化、独立、可重复，且核心增量代码有通过证据。

## 检查流程

1. 确认测试代码位于 `src/test/java`，不进入业务代码目录。
2. 确认测试可以自动执行，无人工交互和外部环境偶然依赖。
3. 确认用例之间相互独立，不依赖执行顺序。
4. 核心业务、核心应用、核心模块的增量代码必须运行相关测试。
5. 数据库相关测试不得假设存量数据必然存在；需要隔离、回滚或构造数据。
6. 完成前报告实际运行的测试命令和结果。

## 输出要求

如果无法补充或运行测试，必须说明阻塞原因和剩余风险。
